# ChurnIQ Deployment Checklist

## Before GitHub
- [ ] Remove private customer datasets
- [ ] Remove `.db` / `.sqlite` files
- [ ] Remove API keys and passwords
- [ ] Confirm `.gitignore` is active
- [ ] Test `streamlit run app.py`

## Before deployment
- [ ] Confirm `requirements.txt`
- [ ] Configure secrets in the hosting dashboard
- [ ] Test authentication
- [ ] Test every sidebar page
- [ ] Test CSV downloads
- [ ] Test with a clean environment

## Portfolio demo
- [ ] Add 2–3 screenshots to README
- [ ] Add project architecture diagram
- [ ] Add GitHub repository link to resume
- [ ] Add live demo link when deployed
